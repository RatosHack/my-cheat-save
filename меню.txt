Ниже представлено максимально подробное описание логики работы открытия/закрытия меню с помощью тройного касания тремя пальцами. Это описание можно использовать как техническое задание для разработчика или для самостоятельной реализации.

---

Логика открытия/закрытия чит-меню через 3 тапа 3 пальцами

1. Общее описание

Меню должно открываться и закрываться при выполнении пользователем тройного касания тремя пальцами в любом месте экрана. Жест должен распознаваться системой глобально, независимо от того, какое приложение активно (игра или домашний экран).

---

2. Условия срабатывания жеста

Параметр Значение
Количество пальцев 3
Количество касаний (тапов) 3 (каждый палец должен коснуться и оторваться)
Временное окно Все 3 касания должны произойти в течение 0.5–0.7 секунды
Зона экрана Любая (по всей площади экрана)
Положение пальцев Не важно, в одной линии или вразброс
Интервал между касаниями Не более 200 мс между первым и последним касанием

---

3. Логика работы

3.1. Распознавание жеста

1. Система отслеживает все касания на экране.
2. При первом касании запускается таймер окна распознавания (например, 700 мс).
3. Счетчик касаний увеличивается на 1.
4. Если в течение тайм-окна зафиксировано ровно 3 касания и каждое касание выполнено ровно 3 пальцами, жест считается успешным.
5. Если количество пальцев в каком-либо касании отличается от 3 — сброс счетчика и таймера.

3.2. Действие при успешном жесте

· Если меню скрыто → показать меню (анимированное появление).
· Если меню видно → скрыть меню (анимированное исчезновение).

3.3. Игнорирование жестов

· Если таймер истек (пользователь не сделал 3 касания за отведенное время) — сброс состояния, меню не меняет состояние.
· Если во время ожидания жеста произошло касание с другим количеством пальцев — сброс.
· Касания должны быть четкими: палец коснулся и оторвался. Долгое удержание не считается тапом.

---

4. Поведение меню при открытии/закрытии

Событие Анимация Поведение
Открытие Плавное появление (fade in + scale) Меню становится активным, перехватывает касания в своей области
Закрытие Плавное исчезновение (fade out + scale) Меню перестает перехватывать касания, весь экран снова доступен для игры

---

5. Технические требования к реализации

5.1. На уровне операционной системы (iOS/macOS)

· Использовать UIGestureRecognizer с кастомной логикой или UITouch напрямую.
· Подключить распознаватель жестов к главному окну приложения (UIWindow), чтобы жест работал в любом месте.

5.2. На уровне веб-интерфейса (HTML/JS)

· Отслеживать события touchstart и touchend.
· Вести учет:
  · touchCount – количество одновременных касаний.
  · tapSequence – массив времен каждого тапа.
· Использовать setTimeout для сброса состояния по истечении времени.

---

6. Пример псевдокода (JavaScript для веб-оверлея)

```javascript
let tapCount = 0;
let tapTimer = null;
let expectedFingers = 3;
let timeWindow = 700; // мс

function onTouchStart(event) {
    let fingers = event.touches.length;
    
    if (fingers !== expectedFingers) {
        resetGesture();
        return;
    }
    
    if (tapCount === 0) {
        tapTimer = setTimeout(resetGesture, timeWindow);
    }
    
    tapCount++;
    
    if (tapCount === expectedFingers) {
        clearTimeout(tapTimer);
        toggleMenu();
        resetGesture();
    }
}

function resetGesture() {
    tapCount = 0;
    if (tapTimer) clearTimeout(tapTimer);
}

function toggleMenu() {
    let menu = document.getElementById("cheat-menu");
    if (menu.style.display === "none" || !menu.style.display) {
        menu.style.display = "block";
        // анимация появления
    } else {
        menu.style.display = "none";
        // анимация исчезновения
    }
}

document.addEventListener("touchstart", onTouchStart);
```

---

7. Требования к анимации

· Появление: opacity 0 → 1, scale 0.9 → 1 за 150–200 мс.
· Исчезновение: opacity 1 → 0, scale 1 → 0.9 за 150–200 мс.

---

8. Обработка краевых случаев

Ситуация Действие
Пользователь начал жест, но не закончил Сброс через таймер, меню не меняется
Во время ожидания жеста появилось другое системное окно (уведомление) Жест прерывается, состояние сбрасывается
Игра в ландшафтном режиме Жест работает так же, координаты не важны
Меню уже открыто и пользователь пытается его закрыть через жест Меню закрывается

---

9. Дополнительная визуальная обратная связь (опционально)

При успешном распознавании жеста можно добавить:

· Вибрацию (легкий тактильный отклик).
· Кратковременную вспышку по краям экрана.
· Звуковой сигнал (щелчок).

---

10. Итог

Меню открывается и закрывается только по жесту: 3 быстрых касания 3 пальцами в любом месте экрана. Жест не конфликтует с обычными игровыми касаниями (1–2 пальца) и не требует нажатия на конкретную область.
